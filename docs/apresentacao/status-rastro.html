Arquitetura

Da visita ao plano de ação

Captura da visita
O navegador exporta um HAR com as requisições e respostas. O Playwright também permite gravar a navegação pelo Rastro.
Identificação e evidências
O núcleo em Python reconhece assinaturas nos scripts. Uma CLI de IA opcional sugere bibliotecas em arquivos agrupados. As regras conferem o trecho, o pacote e a versão.
Consulta e prioridade
GitHub Advisory e OSV fornecem avisos. O NVD complementa a gravidade. O código verifica as versões afetadas e calcula a prioridade.
Entrega do resultado
As checagens de cabeçalhos e cookies se juntam aos achados no plano. React e TypeScript exibem os dados em um HTML único, empacotado com Vite. O JSON fica disponível para outros usos.

Método de trabalho

Como a equipe conduz o projeto

Especificar
O grupo registra os requisitos e os critérios de aceite antes de implementar. O design documenta a arquitetura, as fórmulas e o papel da IA.
Implementar uma tarefa
O grupo orienta o agente de IA em uma tarefa por vez. Os padrões de Python e React ficam versionados com o projeto.
Testar e revisar
Os critérios têm testes identificados pelo requisito ou um roteiro de verificação visual. Outro integrante revisa a mudança e participa como coautor.
Registrar o aceite
O Kanban acompanha a passagem de cada tarefa por implementação, revisão e aceite. Ajustes de revisão ficam no histórico de commits.
